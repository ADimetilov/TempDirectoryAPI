    Temp Directory - утилита с программным интерфейсом (API) 
    Позволяющая создавать директории с временем нахождения их в хранилище.
    После истечения срока директория будет удалена в указанное время. 

    config.py в корневой директории содержит основные конфигурации

    Запуск:

    py -m pip install -r requirements.txt
    py main.py
